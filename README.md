# 나이트 시티 공략집 — Cyberpunk 2077 Guide

사이버펑크 2077 **2.x 패치 + 팬텀 리버티** 기준 공략 웹 애플리케이션입니다.
빌드 도구나 프레임워크 없이 순수 HTML · CSS · Vanilla JavaScript로 만들어 GitHub Pages에 바로 배포할 수 있습니다.

🔗 **사이트:** https://hwimori81.github.io/cb2077_guide/

## 주요 기능

- **진행도 체크리스트** — 신화 무기, 타로 카드, 픽서 의뢰, 놓치면 끝인 아이템, 무료 차량을 체크하면 브라우저 `localStorage`에 자동 저장됩니다. 전체·카테고리·섹션별 달성률과 `n / 총 개수`가 실시간으로 표시됩니다.
- **실시간 검색** — 무기명, 퀘스트명, 구역, 태그, 본문을 즉시 검색합니다. 현재 탭에 결과가 없으면 결과가 있는 탭으로 이동하고, 탭마다 결과 개수를 보여 줍니다. 단축키 `/`로 검색창에 들어갈 수 있습니다.
- **빠른 필터** — 전체 / 미완료만 보기 / 놓치면 끝 / 완료됨
- **스포일러 가림막** — 엔딩 조건, DLC 분기, 로맨스 등은 기본으로 흐리게 처리되며 `[스포일러 확인하기]`를 눌러야 보입니다. 전체 공개 토글도 있습니다.
- **반응형 UI** — PC에서는 좌측 사이드바와 넓은 카드 그리드, 모바일에서는 하단 고정 탭바와 한 줄 카드 레이아웃을 사용합니다.

| 탭 | 내용 |
| --- | --- |
| 육성 & 시스템 | 출신(라이프패스)별 차이, 능력치·특전 초기화 규칙, 사이버웨어 수용량, 부위별 추천 사이버웨어 |
| 추천 빌드 | 넷러너(퀵핵 콤보·오버클럭), 산데비스탄(아포지·카타나), 건슬링어(파워·테크·스마트) |
| 스토리 분기 & 주의사항 | 본편 엔딩 조건표, 히든 엔딩 「사신」, 팬텀 리버티 「화염의 날개」 분기, 로맨스 조건, 놓치면 끝인 아이템 |

## 파일 구조

```
.
├── index.html      # 페이지 구조
├── css/
│   └── style.css   # 다크 네온 테마, 반응형 레이아웃
└── js/
    ├── data.js     # 공략 데이터 (여기만 고치면 내용 추가/수정 가능)
    └── app.js      # 탭 전환, 검색·필터, 체크리스트 저장, 스포일러 토글
```

## 로컬에서 실행

별도 설치 없이 `index.html`을 브라우저로 열면 됩니다. 로컬 서버로 보고 싶다면:

```bash
python -m http.server 8000
# http://localhost:8000 접속
```

## 배포 (GitHub Pages)

저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 지정하고 저장하면 몇 분 뒤 사이트가 열립니다.

## 공략 데이터 추가·수정

모든 내용은 [`js/data.js`](js/data.js)의 `GUIDE` 객체에 있습니다. 파일 상단 주석에 필드 설명이 있습니다.

카드 항목 예시:

```js
{
  id: 'ic-skippy',              // 고유 ID (체크 기록 저장 키 — 한 번 정하면 바꾸지 마세요)
  title: '스키피 (Skippy)',
  sub: '스마트 권총 · 말하는 총',
  tags: ['신화 무기', '권총', '스마트'],
  meta: { '획득처': '사이드 잡 「머신 건」 시작 지점', '보관함 전시': '○ 전시 가능' },
  body: '본문 (간단한 HTML 허용)',
  check: 'iconic',              // 체크리스트 그룹 (GUIDE.checkGroups의 key)
  missable: false,              // true면 '놓치면 끝' 배지 + 필터 대상
  spoiler: false,               // true면 본문 블러 처리
}
```

- 새 체크리스트 그룹을 만들려면 `GUIDE.checkGroups`에 `{ key, label }`을 추가하세요.
- 표 형식 섹션은 `type: 'table'`과 `columns`, `rows`로 작성합니다.
- 기존 항목의 `id`를 바꾸면 사용자의 체크 기록이 연결되지 않으니 주의하세요.
